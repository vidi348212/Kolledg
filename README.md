# Student Monitor - Система мониторинга учеников

Программа для отслеживания активности учеников на уроках информатики.

## Возможности

- **Идентификация учеников**: Запрос фамилии и имени в начале урока
- **Мониторинг процессов**: Отслеживание запуска новых программ
- **Расписание уроков**: Автоматическое определение начала и конца уроков
- **Отображение имени ученика**: Полупрозрачная плашка с именем на экране
- **Расширенный мониторинг** (опционально):
  - Отслеживание операций с файлами
  - Мониторинг посещаемых сайтов в браузерах
  - Защита от установки программ (с паролем учителя)

## Требования

- Python 3.8+
- ОС: Windows 10/11 (полная поддержка), Linux (базовая поддержка)
- Обязательные зависимости: `psutil`
- Опциональные зависимости: `watchdog`, `pygetwindow`

## Установка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <repository-directory>
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка

Отредактируйте файлы конфигурации:

- `schedule.json` - расписание уроков
- `settings.json` - настройки мониторинга

## Запуск

```bash
python student_monitor.py
```

### Тестовый режим

```bash
python student_monitor.py --test
```

## Конфигурация

### schedule.json

Пример расписания:

```json
{
    "lessons": [
        {"lesson": 1, "start": "08:30", "end": "09:15"},
        {"lesson": 2, "start": "09:25", "end": "10:10"}
    ],
    "ask_name_every_lesson": true
}
```

### settings.json

Основные настройки:

```json
{
    "teacher_password": "12345",
    "file_monitoring": {
        "enabled": false,
        "monitor_all_drives": true,
        "folders": ["Desktop", "Documents"],
        "excluded_folders": ["C:\\Temp"],
        "excluded_extensions": [".tmp", ".log"]
    },
    "browser_monitoring": {
        "enabled": false,
        "browsers": ["chrome.exe", "msedge.exe", "firefox.exe"],
        "check_interval_seconds": 5
    },
    "install_guard": {
        "enabled": false,
        "installer_keywords": ["setup", "install", "msiexec"]
    }
}
```

## Автозагрузка

### Windows

Запустите `setup_autostart.bat` для добавления программы в автозагрузку.

### Linux

Запустите `setup_autostart.sh` для создания .desktop файла в автозагрузке.

## Очистка

### Windows

Запустите `cleanup_all.bat` для удаления временных файлов.

### Linux

Запустите `cleanup_all.sh` для удаления временных файлов.

## Особенности работы

### Windows

- Используется системный мьютекс для предотвращения двойного запуска
- Поддержка звуковых уведомлений через winsound
- Полная поддержка всех функций мониторинга

### Linux

- Используется файловая блокировка для предотвращения двойного запуска
- Звуковые уведомления через системный bell
- Базовая поддержка мониторинга процессов

## Логирование

Программа создаёт три типа логов в папке `logs/`:

1. `debug.txt` - подробный отладочный лог
2. `errors.txt` - журнал критических ошибок
3. `student_log_YYYYMMDD.txt` - ежедневные логи активности учеников

## Устранение проблем

### Программа не запускается

1. Проверьте установлен ли Python 3.8+
2. Установите зависимости: `pip install -r requirements.txt`
3. Проверьте права доступа к папке программы

### Ошибки мониторинга файлов

Убедитесь, что установлена библиотека `watchdog`:

```bash
pip install watchdog
```

### Не работает мониторинг браузеров

Убедитесь, что установлена библиотека `pygetwindow`:

```bash
pip install pygetwindow
```
