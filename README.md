# 📚 Система мониторинга класса (Class Monitor System)

Система для управления компьютерами учеников в классе с компьютера учителя.

## 📁 Структура проекта

```
/workspace/
├── common/                    # Общие модули
│   ├── __init__.py
│   └── network_utils.py       # Сетевые утилиты и константы
│
├── student_client/            # Клиент для компьютера ученика
│   ├── __init__.py
│   ├── client.py              # Основной код клиента
│   └── run_client.bat         # Скрипт запуска (Windows)
│
├── teacher_console/           # Консоль учителя
│   ├── __init__.py
│   └── server.py              # Сервер + GUI интерфейс
│
└── requirements.txt           # Зависимости Python
```

## 🚀 Возможности системы

### Для учителя:
- ✅ **Автоматическое обнаружение** всех компьютеров учеников в сети
- ✅ **Мониторинг в реальном времени**: статус, активное окно, имя студента
- ✅ **Блокировка компьютера** ученика с сообщением
- ✅ **Режим контрольной работы** (ограничение доступа)
- ✅ **Получение скриншотов** экрана ученика
- ✅ **Отправка сообщений** отдельным ученикам или всем сразу
- ✅ **Удалённая блокировка экрана** (Win+L)
- ✅ **Завершение процессов** на компьютере ученика
- ✅ **Выключение/перезагрузка** компьютеров учеников
- ✅ **Управление всеми компьютерами** одновременно

### Для ученика:
- 🔹 Автоматическое подключение к серверу учителя
- 🔹 Получение команд и их выполнение
- 🔹 Отображение сообщений от учителя
- 🔹 Логирование всех событий
- 🔹 Работа в фоновом режиме

## 📋 Требования

- **ОС**: Windows 10/11 (требуется для полной функциональности)
- **Python**: 3.8 или выше
- **Сеть**: Все компьютеры должны быть в одной локальной сети

## 🔧 Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка на компьютере учителя

1. Запустите сервер учителя:
```bash
python teacher_console/server.py
```

2. Откроется графический интерфейс управления классом

### 3. Настройка на компьютерах учеников

1. Запустите клиента (можно добавить в автозагрузку):
```bash
python student_client/client.py --name "Имя Фамилия"
```

2. Или используйте пакетный файл:
```bash
student_client\run_client.bat
```

3. Для автозагрузки добавьте ярлык в папку автозагрузки Windows:
   - Нажмите `Win + R`
   - Введите `shell:startup`
   - Создайте ярлык на `run_client.bat`

## 🎮 Использование

### Запуск учителя

```bash
cd /workspace
python teacher_console/server.py
```

Интерфейс учителя автоматически:
- Запустит сервер на порту 54321
- Начнёт широковещательный поиск клиентов
- Отобрит подключенных компьютеров учеников

### Запуск клиента

```bash
cd /workspace
python student_client/client.py --name "Иванов Иван"
```

Клиент автоматически:
- Найдёт сервер учителя через широковещательную рассылку
- Подключится к серверу
- Будет отправлять статус каждые 30 секунд
- Выполнять полученные команды

## 🎯 Команды сервера

| Команда | Описание |
|---------|----------|
| `get_status` | Получить статус компьютера |
| `block_pc` | Заблокировать компьютер |
| `unblock_pc` | Разблокировать компьютер |
| `start_test` | Включить режим тестирования |
| `stop_test` | Выключить режим тестирования |
| `get_screenshot` | Сделать скриншот экрана |
| `get_process_list` | Получить список процессов |
| `kill_process` | Завершить процесс |
| `lock_screen` | Заблокировать экран (Win+L) |
| `shutdown` | Выключить компьютер |
| `restart` | Перезагрузить компьютер |
| `send_message` | Показать сообщение |

## 🔐 Безопасность

⚠️ **Важно**: Система предназначена для использования только в образовательных целях в локальной сети класса.

- Все соединения происходят только внутри локальной сети
- Нет выхода в интернет
- Логи хранятся локально в папке `logs/`

## 📝 Логи

Логи сохраняются в папках:
- `student_client/logs/` - логи клиента
- `teacher_console/logs/` - логи сервера

Формат имени файла: `client_YYYYMMDD.log` или `server_YYYYMMDD.log`

## 🛠️ Настройка сети

### Порты
- **54321** - TCP порт для соединений клиент-сервер
- **54322** - UDP порт для широковещательного обнаружения

### Брандмауэр Windows

Если клиенты не подключаются, добавьте исключения в брандмауэр:

```powershell
# Разрешить Python
netsh advfirewall firewall add rule name="Python Server" dir=in action=allow program="C:\Python39\python.exe" enable=yes

# Или открыть порты
netsh advfirewall firewall add rule name="Student Monitor TCP" dir=in action=allow protocol=TCP localport=54321
netsh advfirewall firewall add rule name="Student Monitor UDP" dir=in action=allow protocol=UDP localport=54322
```

## ❓ Решение проблем

### Клиент не видит сервер
1. Проверьте, что оба компьютера в одной сети
2. Проверьте брандмауэр
3. Убедитесь, что сервер запущен

### Сервер не показывает учеников
1. Подождите 30-60 секунд (клиент отправляет статус периодически)
2. Проверьте логи клиента на ошибки подключения

### Ошибка при блокировке экрана
- Функция `LockWorkStation` доступна только на Windows
