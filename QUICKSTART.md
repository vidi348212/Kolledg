# 🚀 Быстрый старт

## Установка зависимостей
```bash
pip install -r requirements.txt
```

## Запуск на компьютере учителя
```bash
python teacher_console/server.py
```
Откроется графический интерфейс управления классом.

## Запуск на компьютерах учеников
```bash
python student_client/client.py --name "Фамилия Имя"
```

Или используйте пакетный файл (Windows):
```bash
student_client\run_client.bat
```

## Для автозагрузки клиента (Windows)
1. Нажмите `Win + R`
2. Введите `shell:startup`
3. Создайте ярлык на `student_client\run_client.bat`

## Проверка работы
1. Запустите сервер учителя
2. Запустите клиента на другом компьютере (или в другом окне терминала)
3. Клиент должен автоматически найти сервер и появиться в списке

## Порты
- **54321/TCP** - соединение клиент-сервер
- **54322/UDP** - обнаружение клиентов

Если клиенты не подключаются, проверьте брандмауэр Windows!
