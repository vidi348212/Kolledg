# 🎓 Student Monitor - Сетевая система мониторинга класса

## 📋 Описание

Система для мониторинга компьютеров учеников в классе с поддержкой:
- **Автоматического ввода имени** по расписанию уроков
- **Плашки с именем** в верхней части экрана (перемещаемая)
- **Сетевого взаимодействия** между учителем и учениками
- **Управления компьютерами** учеников с компьютера учителя

## ⚙️ Функционал

### Для ученика:
1. **Ввод имени по расписанию** - окно появляется автоматически в начале каждого урока
2. **Плашка с именем** - отображается вверху экрана по центру:
   - Размер адаптируется под длину имени
   - Можно перетаскивать мышью в пределах верхней области (100px)
   - Исчезает через 5 минут после окончания последнего урока
3. **Автоматическое закрытие окна ввода** - если урок закончился, а имя не введено
4. **Звуковой сигнал** - звонок на начало/конец урока
5. **Сетевое соединение** - отправка статуса учителю

### Для учителя:
1. **Обнаружение всех компьютеров** в сети автоматически
2. **Мониторинг в реальном времени**:
   - Имя ученика
   - Текущий урок
   - Активное окно
   - IP-адрес и статус
3. **Управление классом**:
   - Блокировка компьютера с сообщением
   - Отправка сообщений (одному или всем)
   - Получение скриншотов
   - Удалённая блокировка экрана (Win+L)
   - Завершение процессов
   - Выключение/перезагрузка компьютеров
4. **Режим контрольной работы** - ограничение доступа к программам

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка расписания

Откройте `student_client/config.json` и отредактируйте расписание:

```json
{
    "schedule": {
        "enabled": true,
        "lessons": [
            {"start": "08:30", "end": "09:15", "name": "Урок 1"},
            {"start": "09:25", "end": "10:10", "name": "Урок 2"}
        ],
        "overlay_timeout_minutes": 5
    }
}
```

### 3. Запуск на компьютере учителя

```bash
cd teacher_console
python server.py
```

Или дважды кликните на `server.py` в проводнике.

### 4. Запуск на компьютерах учеников

```bash
cd student_client
python client.py
```

Или используйте `run_client.bat`.

## 🔧 Конфигурация

### student_client/config.json

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `network.teacher_ip` | IP учителя (null = автообнаружение) | null |
| `network.port_command` | Порт для команд | 54321 |
| `network.port_discovery` | Порт для обнаружения | 54322 |
| `schedule.enabled` | Включить расписание | true |
| `schedule.lessons` | Список уроков | [] |
| `schedule.overlay_timeout_minutes` | Время показа плашки после урока | 5 |

## 🎯 Как это работает

### Ввод имени и плашка

1. **Начало урока** (согласно расписанию):
   - Если имя не введено → появляется окно ввода
   - Окно блокирует закрытие до ввода имени
   - После ввода → окно закрывается, показывается плашка

2. **Во время урока**:
   - Плашка отображает имя и название урока
   - Можно перетаскивать в пределах верхней области
   - При смене урока → обновляется название урока

3. **Конец урока**:
   - Если следующий урок еще не начался и компьютер пуст → окно ввода закрывается
   - После последнего урока → плашка исчезает через 5 минут

4. **Переход между уроками**:
   - Если имя уже введено → обновляется только название урока на плашке
   - Новое окно ввода не появляется

### Сетевое взаимодействие

```
Учитель (Server)          Ученики (Clients)
     │                          │
     ├─ UDP Broadcast ─────────►│ (Обнаружение)
     │◄─────── Response ────────┤
     │                          │
     ├─ TCP Connection ────────►│ (Подключение)
     │◄────── Heartbeat ────────┤ (Статус каждые 30 сек)
     │                          │
     ├────── Commands ─────────►│ (Блокировка, сообщения)
     │◄─────── Screenshot ──────┤ (По запросу)
```

## 📝 Примечания

- **Только Windows** - система использует Windows-specific API
- **Требуется Python 3.8+**
- **Сеть** - все компьютеры должны быть в одной локальной сети
- **Брандмауэр** - откройте порты 54321/TCP и 54322/UDP

## 🔐 Безопасность

- Все соединения внутри локальной сети
- Нет передачи данных во внешнюю сеть
- Логи хранятся локально в папке `logs/`

## 🛠️ Расширение функционала

Для добавления новых функций:
1. Измените `common/network_utils.py` для новых типов команд
2. Добавьте обработчики в `client.py` и `server.py`
3. Обновите GUI учителя при необходимости

## 📞 Поддержка

При возникновении проблем проверьте:
1. Логи в папке `student_client/logs/`
2. Настройки брандмауэра
3. Корректность расписания в `config.json`
4. Что все ПК в одной сети
